## runtime.config.inspect

Read the deployment-owned Stellar network policy and Classic/Soroban managed execution availability.

**HTTP:** `GET /runtime-config`  
**Access:** `public` · **Effect:** `none`

**Authentication:** public

**Response 200** — Successful operation.

  "operation": "runtime.config.inspect",
  "version": 1,
  "stellarNetwork": "testnet",
  "fixedNetwork": "testnet",
  "capabilities": {

      "public": false,
      "testnet": false
    },
    "sorobanManagedExecution": {
      "public": false,
      "testnet": false

}
