## contract.intent.create

Create a source-free Soroban Intent and discover its authorization plan. An Agent Principal must be a current signer for at least one required authorizer unless no authorization is required.

**HTTP:** `POST /intent`  
**Access:** `principal:write` · **Effect:** `coordination-state`

**Authentication:** `agentBearer` or `humanBearer` or `humanSession`

| Parameter | Location | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `x-multisig-session-address` | header | Conditional / optional | Must match the Human session signer for selected-wallet verification. Required for Human-authorized operations that use a selected wallet; not used for machine credentials. | `GB6M5I2JKWBMJ6H6N3WGFE377VVGL4VOQD6PHFRZRA2VXKHZBT5QOP3P` |
| `Idempotency-Key` | header | Conditional / optional | Required for Agent or Integration Intent creation; Human sessions do not need it. | `example-transfer-01` |
