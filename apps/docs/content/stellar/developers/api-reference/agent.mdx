| `x-multisig-session-address` | header | Yes | Must match the Human session signer for selected-wallet verification. Required for Human-authorized operations that use a selected wallet; not used for machine credentials. | `GB6M5I2JKWBMJ6H6N3WGFE377VVGL4VOQD6PHFRZRA2VXKHZBT5QOP3P` |

**Request example**

```json
{
  "credentialId": "example-credential"
}
```
