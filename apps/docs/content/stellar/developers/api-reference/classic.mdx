## classic.payment.prepare

**HTTP:** `POST /payment-prepare`  
**Access:** `principal:write` · **Effect:** `none`

**Authentication:** `agentBearer` or `humanBearer` or `humanSession`

    {
      "destination": "GDJXYXYMPGVWATWB7KUC6C5KGB3DDUWP76WBPBAL5V4WN6UUR6JKWWXB",

      "asset": {
        "type": "native"

  "lifetimeSeconds": 3600
