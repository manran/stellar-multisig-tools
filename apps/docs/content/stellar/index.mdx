MultiSig Tools coordinates review, authorization, and execution around exact Stellar work.

## Start from the job, not the protocol

Human guides use product language first. Developer pages expose Request, Intent, XDR, AUTH, idempotency, and execution where those details become the task.

### Start

- [Sign a Proposal](/stellar/start/sign-a-proposal) — review one exact Stellar transaction and add your signature.
- [Create a Treasury](/stellar/start/create-a-treasury) — configure shared authorization for a Stellar account.
